# BEMPIC Reference development freeze — 2026-09-02

BEMPIC Reference development is halted/frozen with the BEMPIC specification project.

The repository remains Apache-2.0 experimental research. It is not v0.1.0 conformant, not release-ready, and does not define a stable public wire format.

The exact pre-freeze generation is preserved on `archive/v0.1-generation`.

## Reason

OceanMail 0.2 has moved from the clean-sheet OceanMail -> BEMPIC -> M4P implementation path to an upstream-first HERMES/Mercury path. The immediate goal is to establish and measure a real HERMES-derived store-forward email baseline before deciding whether a new application synchronization protocol is justified.

## Freeze rules

- Preserve code, tests, vectors, fixtures, and evidence.
- Do not continue codec, conformance, feature, or release work merely to finish the former v0.1 roadmap.
- Do not claim v0.1.0 conformance or stable-wire compatibility.
- Maintenance/security corrections necessary to preserve the research accurately are acceptable; new protocol-development work requires an explicit decision to lift the freeze.

## Resume condition

Reference implementation work may resume only if BEMPIC itself is reactivated after direct comparison against the HERMES `UUCP + uuxcomp` baseline under the same constrained-link/modem conditions demonstrates material value worth implementing and maintaining.
