# Public experimental codec vectors

These vectors exercise the allocated experimental tuple `0x00010000/1`.
Allocation does not make the codec approved, mandatory, stable, suitable for
private traffic, or sufficient for v0.1.0 conformance.

`vectors.json` is generated by:

```text
cargo run -p bempic-conformance -- write-compact-codec-evidence
```

The neighboring `v0.1-compact-candidate` directory is historical provenance
for the former private tuple `0xffff0001/2`. It is not active conformance
evidence and is not compatible with this public tuple.
